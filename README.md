# الذكاء الاصطناعي المسؤول بالتصميم لفرق المنتجات

Responsible AI by Design for Product Teams

مسار التنفيذيين والقادة · أكاديمية سدايا · LDS-PRD-301 · المستوى 300

REPLACE: سطر واحد تحت العنوان: ما يستطيع المشارك فعله بعد المقرر

ينقل المشاركون مساعدًا افتراضيًا لخدمة الإعانات، يصوغ مسودات قرارات الأهلية للأخصائيين المسؤولين عن الحالات، إلى مراجعة الإطلاق: أضرار مرتبة، وضوابط حماية مختبرة لها مالكون، وإفصاح وحق في التظلم، ونموذج إشراف مقيس، وقرار بالإطلاق أو الإطلاق المشروط أو عدم الإطلاق. ويغطي المقرران LDS-AIG-303 وLDS-AIG-307 تقييم الأثر وإجراءات الإشراف بتعمق.

**الصيغة:** ورشة عمل: يوم ونصف مع مراجعة إطلاق بالمحاكاة

**صفحة المقرر:** https://sdaiaacademy.github.io/lds-prd-301/

## نواتج التعلم

| | نواتج التعلم | المستوى | الدليل |
|---|---|---|---|
| LO1 | يحلل الأضرار عبر الفئات المتأثرة والإخفاق وسوء الاستخدام والتوسع، مرتبة بحسب الشدة والاحتمالية وقابلية التراجع، استنادًا إلى المواصفات والشخصيات الافتراضية وقائمة مرجعية للتحيز | Applied | سجل أضرار مرتب يشمل غير المستخدمين |
| LO2 | يصوغ ضوابط الحماية في صورة متطلبات لها مالكون واختبارات نتيجتها اجتياز أو إخفاق وشرائح إطلاق للفئات الفرعية، استنادًا إلى الأضرار الخمسة الأعلى ترتيبًا | Applied | قائمة أعمال لضوابط الحماية تربط كل بند بضرر واختبار |
| LO3 | يصوغ إشعارات الإفصاح والتفسير والتظلم للمتقدمين والأخصائيين بالعربية والإنجليزية، استنادًا إلى مسار القرار | Applied | إشعارات يجيب الأقران بعد قراءتها إجابة صحيحة عن أربعة من خمسة أسئلة فهم |
| LO4 | يصمم نموذجًا للإشراف البشري فيه أخذ عينات للمراجعة وسجلات للتجاوز ومقاييس للموافقة الشكلية، استنادًا إلى بيانات عبء العمل لدى الأخصائيين | Performance | مواصفات للإشراف فيها نسب أخذ العينات وعتبات تفعيل المراجعة |
| LO5 | يقرر جاهزية الإطلاق استنادًا إلى نتائج الفئات الفرعية واختبارات ضوابط الحماية والمخاطر القائمة، استنادًا إلى حزمة أدلة وأمام لجنة مراجعة | Performance | سجل إطلاق فيه الشروط ومالكوها، يُناقَش أمام اللجنة |
